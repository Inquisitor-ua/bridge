# Бридж

Браузерная карточная игра для 2-6 игроков в комнатах по WebSocket.
Бэкенд — FastAPI (вся игровая логика и состояние комнаты живут в памяти
процесса, без БД). Фронтенд — Vue 3 + Vite, карты на руке — снизу экрана,
ход делается перетаскиванием карты на игровое поле (drag & drop).

## Запуск в разработке

Бэкенд (команды из корня `bridge/`, не из `backend/` — `main.py` использует
относительные импорты внутри пакета `backend`, поэтому `uvicorn` нужно
указывать как `backend.main:app`, а не `main:app`):

```
cd backend
python -m venv .venv
.venv/Scripts/activate      # или source .venv/bin/activate на *nix
pip install -r requirements.txt
cd ..
uvicorn backend.main:app --reload --port 8000
```

Фронтенд (в отдельном терминале):

```
cd frontend
npm install
npm run dev
```

Открыть http://localhost:5173 — dev-сервер Vite проксирует `/ws` на бэкенд
(см. `frontend/vite.config.js`).

## PWA (установка на телефон)

Фронтенд собирается как PWA (`vite-plugin-pwa`): манифест, иконки и service
worker, который кэширует статику. На Android Chrome предложит «Установить
приложение», на iOS: Safari → «Поделиться» → «На экран Домой». Нужен HTTPS,
на локальном `localhost` тоже работает. Игра всё равно идёт через `/ws`,
офлайн она не работает, кэшируется только оболочка.

Иконки генерируются из `frontend/public/icon.svg` (конфиг в
`frontend/pwa-assets.config.js`), после изменения SVG запустить:

```
cd frontend
npm run icons
```

Service worker обновляется сам (`registerType: "autoUpdate"`): после деплоя
новая версия подхватывается при следующем открытии.

## Деплой (Docker)

Один контейнер `bridge-app`: на этапе сборки Node собирает фронтенд, а в
рантайме uvicorn отдаёт и `frontend/dist` (статикой через FastAPI), и
WebSocket `/ws`. Воркер строго один — комнаты и партии живут в памяти
процесса, поэтому перезапуск контейнера обрывает все текущие игры.

Снаружи его видит общий `edge-nginx` из `../nginx-proxy` через внешнюю
сеть `edge` (порты на хост не публикуются); маршрут для
`bridge.yehor-inq.com` — в `../nginx-proxy/conf.d/bridge.conf`.

Образ собирает GitHub Actions (`.github/workflows/docker.yml`) при каждом
пуше в `main` и публикует в `ghcr.io/inquisitor-ua/bridge:latest` — сервер
слабый, собирать фронтенд на нём долго. На сервере (рядом с `nginx-proxy`,
например `/srv/bridge`), после того как workflow в Actions стал зелёным:

```
cd /srv/bridge && git pull && docker compose pull && docker compose up -d
cd /srv/nginx-proxy && git pull && docker compose restart nginx
```

Если пакет в GHCR приватный, один раз на сервере:
`docker login ghcr.io -u Inquisitor-ua` (пароль — GitHub PAT с правом
`read:packages`). Собрать образ прямо на месте по-прежнему можно через
`docker compose up -d --build`.

В Cloudflare: DNS-запись `bridge` (A на IP сервера, оранжевое облако);
WebSocket в Cloudflare включён по умолчанию. Origin-сертификат
`*.yehor-inq.com` уже покрывает этот поддомен.

## Реализованные правила

- Колода 36 карт (6..10, В, Д, К, Т × 4 масти).
- Раздача: всем по 5 карт, игроку с наибольшим количеством очков — 4
  (его пятая карта кладётся на стол как стартовая). В первом раунде,
  когда у всех 0 очков, дилер выбирается случайно.
- Накрывать можно картой того же номинала или той же масти — но конкретно
  той картой, которая реально совпадает: если на столе король черв, а на
  руках восьмёрка черв и восьмёрка треф, ходить можно только червовой
  восьмёркой; трефовую можно только доложить следующей, когда червовая
  уже лежит на столе. Ход не передаётся автоматически после одной карты:
  можно продолжать докладывать карты того же номинала, что уже лёг в этом
  ходу (сколько угодно штук) — но сменить номинал внутри одного хода
  нельзя, даже если новая карта совпадает по масти с той, что легла
  последней: чтобы сыграть другим номиналом, нужно сперва закончить
  текущий ход. Только сам игрок решает, когда закончить ход (кнопка
  «Закончить ход» / «Пас») — до этого момента форсированный эффект его
  карт (7/8/дама пик/туз) на соперника ещё не действует.
- Ходить необязательно, даже если есть чем: в свой обычный ход игрок
  может один раз взять карту из колоды (кнопка «Взять карту», доступна,
  только пока он ещё не брал в этот ход и ещё не клал карт — после хода
  картой можно только доложить тот же номинал или закончить ход; исключения —
  шестёрка и случай, когда пропуски от 8/туза возвращают ход ему же: тогда
  добор неявно закрывает текущий ход и открывает новый), а затем либо сыграть картой
  (необязательно только что взятой), либо объявить пас и отдать ход
  дальше, ничего не выкладывая — даже если на руке была подходящая карта.
- Исключение — шестёрка: её обязательно должен накрыть тот же игрок,
  который её положил. Ход у него не забирается — лимит в одну карту не
  действует, он обязан брать карты из колоды сколько потребуется и в
  итоге положить карту, накрывающую шестёрку (той же масти, того же
  номинала или валета); пока это не сделано, кнопка «Пас» недоступна.
  Если шестёркой закончилась вся рука игрока, раздача не завершается —
  он всё равно обязан продолжать.
- Спецэффекты: 7 — следующий берёт 1 карту (за N семёрок — N карт);
  8 — тот же игрок берёт 2 карты и пропускает ход (за N восьмёрок — 2N
  карт); дама пик — следующий берёт 5; туз — следующий пропускает ход;
  валет — кладётся на любую карту, игрок объявляет новую масть. После
  валета можно доложить ещё валетов (по одному или сразу несколько), а
  масть выбирается при нажатии «Закончить ход» (если валет был последней
  картой на руке — сразу). Другие карты и добор после валета недоступны.
  Как только масть названа, ход переходит следующему игроку.
- Ходить/брать карту в свой ход не обязательно, но пасовать «вникуда»
  нельзя: прежде чем нажать «Пас», нужно либо сходить хотя бы одной
  картой, либо хотя бы раз взять карту из колоды в этот ход.
- «Бридж»: если на столе подряд оказались 4 десятки, 4 валета, 4 дамы,
  4 короля или 4 туза (четыре шестёрки, семёрки, восьмёрки или девятки
  не считаются), игрок, положивший последнюю, может объявить «Бридж» — раздача сразу
  заканчивается, и все игроки (включая объявившего) считают очки на
  руках.
- Игрок, закончивший раздачу валетом (одним или несколькими), выбирает:
  забрать себе -20 очков за каждый валет, либо умножить очки на руках
  у остальных на (количество валетов + 1).
- Подсчёт очков: 6-9 — 0, 10/В/Д/К — 10, туз — 15, валет в одиночестве
  на руке — 20.
- Если колода заканчивается, стол (кроме верхней карты) перемешивается
  в новую колоду; каждая такая пересдача добавляет +1 к множителю очков
  на руках при подсчёте в конце раздачи.
- Очки суммируются по раундам. Ровно 125 — обнуление и игра продолжается.
  Больше 125 — игрок выбывает, оставшиеся продолжают играть; когда
  остаётся один — он победитель.

## Известные допущения (правила это явно не оговаривали)

- Один ход состоит из одной или нескольких карт одного номинала,
  выложенных за произвольное число действий подряд (можно класть их по
  одной). Первая карта хода (или карта, накрывающая шестёрку — см. ниже)
  должна совпадать по масти или номиналу с тем, что сейчас лежит сверху
  (валет — всегда легален). Как только номинал хода установлен первой
  картой, все последующие карты этого же хода обязаны быть того же
  номинала — доложить карту другого номинала, даже если она совпадает по
  масти с последней выложенной, нельзя; для этого нужно сначала закончить
  ход. Валет легален всегда в начале хода и при накрытии шестёрки, а
  посреди хода — только поверх 8 или туза; поверх любой другой карты
  (король, девятка и т.д.) доложить можно только тот же номинал. За одно действие (один вызов «положить
  карту») все выбранные карты тоже должны быть одного номинала. Эффекты
  спецкарт (7/8/дама пик/туз) суммируются по всем картам, сыгранным за
  ход, но применяются к следующему игроку только когда текущий явно
  заканчивает ход (кнопкой) — пока ход не закончен, форсированный добор
  для соперника не наступает.
- Форсированные эффекты (7/8/дама пик/туз) срабатывают безусловно —
  следующий игрок не может «отбиться» своей картой того же типа, чтобы
  переложить эффект дальше; они просто обязаны взять карты и/или
  пропустить ход.
- Пока игрок не нажал «Закончить ход» / «Пас», накопленные штрафы
  (взятие карт, пропуск хода) для соперника не применяются — они ждут
  окончания хода. Когда ход наконец заканчивается и штрафы срабатывают,
  пропуски (по одному за каждую 8 или туз) достаются только соперникам —
  игрок, который их положил, сам никогда не пропускает: очередь проходит
  мимо него, не расходуя пропуск. Поэтому в игре на двоих любое
  количество 8/тузов возвращает ход тому же игроку, а, например, в игре
  на троих 2 туза пропускают обоих соперников (ход снова ваш), 3 туза —
  соперников по кругу P1, P2, P1, и ходит P2.
- Если накопленные за ход пропуски (8/туз) всё равно вернут ход тому же
  игроку (например, одна восьмёрка в игре на двоих), нажимать «Закончить
  ход» не обязательно: игрок может сразу положить карту в масть/номинал
  верхней (скажем, даму черв на восьмёрку черв). Такой ход неявно
  закрывает предыдущий — соперник берёт штраф и пропускает — и открывает
  новый ход того же игрока. Доложить ещё карту того же номинала (ещё одну
  восьмёрку) по-прежнему можно как продолжение текущего хода.
- Стартовая карта, вскрытая дилером, обрабатывается так, будто дилер сам
  её только что сыграл: ход дилера уже открыт этой картой, и он может
  доложить с руки карты того же номинала (или валета), но брать из колоды
  не может — затем заканчивает ход кнопкой. Если докладывать нечего, ход
  сразу переходит к следующему игроку. Эффект стартовой карты (7/8/дама
  пик/туз), как и любой сыгранной, применяется к следующему игроку, когда
  ход дилера заканчивается (сам дилер эффект своей карты не получает).
  Шестёрка и валет — исключения,
  потому что создают личное обязательство того, чья это карта: если это
  шестёрка, дилер сам обязан её накрыть (см. выше про шестёрку); если
  валет — дилер сам называет масть, а дальше ход, как обычно, переходит
  следующему игроку.
- «Бридж» — это добровольное объявление игрока, докатившего до 4-й карты
  номинала (кнопка выбора «объявить / не объявлять»), а не автоматическое
  событие.
- Реконнект: клиент хранит `room` + `player_id` в localStorage и
  переподключается автоматически при обрыве связи/перезагрузке страницы.
- Выход из комнаты (кнопка «Выйти» в шапке): в лобби игрок просто
  удаляется из комнаты, во время игры — выбывает (его карты уходят под
  колоду, если был его ход — ход переходит дальше); вернуться в ту же
  партию после этого нельзя. Если вышел хост — хостом становится
  следующий игрок; пустая комната удаляется.

## Структура

```
backend/
  cards.py          модель карты, колода, подсчёт очков
  engine.py         вся игровая логика одного раунда/комнаты
  room_manager.py   комнаты, игроки, коды комнат
  main.py           FastAPI + единственный WebSocket-эндпоинт /ws
  smoke_test.py      быстрые проверки движка (python -m backend.smoke_test)
  smoke_ws_test.py   проверка полного цикла через WebSocket API
frontend/
  src/store.js              WebSocket-клиент и реактивное состояние
  src/components/           Lobby, WaitingRoom, GameTable, PlayingCard, промпты
Dockerfile          сборка фронтенда + рантайм uvicorn
docker-compose.yml  контейнер bridge-app в сети edge
```
